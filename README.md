# 余境 · 虚拟艺术馆

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18112 。

## 主题路线（个人版本）

- 导览进行中（行走 / 讲解 / 暂停）都可增删、拖动或按钮重排站点；「保存」生成个人版本，「恢复」回到上次保存的版本。
- **已完成是事实，待完成是意图**：完成记录只按站点实例（occurrence）写入，删除已完成站不会让完成度回退；删除待完成站也不会被算作完成。
- 同一作品可重复加入，每次插入都是新的重访站，不会因作品编号相同而自动完成。
- 实时编辑时当前段保持稳定：正在行走或讲解的作品不会因重排而换成另一件；删除当前站后本段仍会完成，之后按新路线继续。空间导航与播放器都会标明当前段是否继续、属于哪一站。
- 晚到的讲解结束事件带有段身份（token + occurrence），不会计入新站点。
- 收藏回顾会分开显示实际完成、仍待完成、已从计划删除（注明删除前是否真的参观过），以及被删路线的历史参观记录。
